This interactive tutorial series walks you through the core concepts of GitOps by building on a real workflow with Strimzi and Argo CD. Before diving in, we recommend reading the [Introduction to GitOps](../introduction) article. It covers the problems that GitOps solves, contrasts it with the manual approach most teams start with and introduces the key ideas you will see in practice throughout these lessons.

The series is designed to be followed in order, however the lessons are self-contained so you can jump ahead if you wish. [Lesson 1](lesson-1-companion-guide.md) introduces infrastructure as code and automated reconciliation by guiding you through your first GitOps change. [Lesson 2](lesson-2-companion-guide.md) builds on that foundation with multi-environment management, showing how the Kustomize base and overlay pattern enables your project to scale. [Lesson 3](lesson-3-companion-guide.md) tackles what happens when things go wrong, covering health monitoring and rollback using nothing more than a `git revert`. Finally, the [Wrapping Up](wrapping-up.md) guide summarizes the principles you've learned and gives some ideas for your next steps.
